# Genomes

Put one FASTA file per genome here (for example `GUT_GENOME000123.fna`).
The file name, without the extension, is used as the genome ID.

These files are **not** stored on GitHub (see `.gitignore`); they are too large.

## Where the thesis genomes came from

| Source | What | Link |
|---|---|---|
| UHGG (Unified Human Gastrointestinal Genome) | Isolate genomes and MAGs from the human gut | https://www.ebi.ac.uk/metagenomics/browse/genomes |
| SPIRE | Metagenome-assembled genomes from public studies | https://spire.embl.de |

For a quick demo, download 20–30 *Blautia* genomes from UHGG (search the catalogue
for the genus *Blautia*) and save them here with the `.fna` extension.

Unpublished isolate genomes from the lab collection are not included in this repository.
